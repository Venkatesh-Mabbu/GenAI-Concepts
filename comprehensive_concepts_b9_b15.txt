        <h2>Fine-Tuning Models: Customizing AI for Your Needs</h2>
        <p>Fine-tuning is the process of taking a pre-trained model and adapting it to perform specific tasks or work with domain-specific data. It's one of the most practical techniques in modern AI, enabling developers to create customized, high-performing models without starting from scratch.</p>

        <h3>What is Fine-Tuning?</h3>
        <p>Fine-tuning involves taking a model that has already been trained on a large general dataset and continuing to train it on a smaller, more specific dataset. The model retains its general knowledge while learning task-specific or domain-specific patterns.</p>

        <h3>Why Fine-Tune?</h3>
        <ul>
            <li><strong>Domain Specificity:</strong> Adapt general models to specialized fields (medical, legal, financial)</li>
            <li><strong>Task Adaptation:</strong> Customize for specific tasks (sentiment analysis, entity recognition)</li>
            <li><strong>Improved Performance:</strong> Often outperforms general models on specific tasks</li>
            <li><strong>Data Efficiency:</strong> Requires far less data than training from scratch</li>
            <li><strong>Cost Effective:</strong> Saves compute resources and time</li>
            <li><strong>Proprietary Knowledge:</strong> Incorporate your organization's unique data and expertise</li>
        </ul>

        <h3>Types of Fine-Tuning</h3>

        <h4>1. Full Fine-Tuning</h4>
        <p>Update all parameters in the model:</p>
        <pre><code>
from transformers import AutoModelForSequenceClassification, Trainer, TrainingArguments
import torch

# Load pre-trained model
model = AutoModelForSequenceClassification.from_pretrained(
    'bert-base-uncased',
    num_labels=3  # e.g., positive, negative, neutral
)

# All parameters will be updated during training
for param in model.parameters():
    param.requires_grad = True

# Set up training arguments
training_args = TrainingArguments(
    output_dir='./results',
    num_train_epochs=3,
    per_device_train_batch_size=8,
    learning_rate=2e-5,  # Small learning rate important!
    warmup_steps=500,
    weight_decay=0.01,
    logging_steps=100,
    evaluation_strategy='epoch',
    save_strategy='epoch',
    load_best_model_at_end=True
)

# Create trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    compute_metrics=compute_metrics
)

# Fine-tune
trainer.train()
        </code></pre>

        <p><strong>When to use:</strong> You have sufficient data (1000+ examples) and computational resources</p>
        <p><strong>Advantages:</strong> Maximum performance, full adaptation to your task</p>
        <p><strong>Disadvantages:</strong> More expensive, risk of overfitting, requires more data</p>

        <h4>2. Parameter-Efficient Fine-Tuning (PEFT)</h4>
        <p>Update only a small subset of parameters:</p>

        <h5>LoRA (Low-Rank Adaptation)</h5>
        <p>Adds trainable low-rank matrices to transformer layers:</p>
        <pre><code>
from peft import get_peft_model, LoraConfig, TaskType

# Configure LoRA
lora_config = LoraConfig(
    task_type=TaskType.SEQ_CLS,
    r=8,  # Rank of adaptation matrices
    lora_alpha=32,
    lora_dropout=0.1,
    target_modules=['query', 'value']  # Which layers to adapt
)

# Apply LoRA to model
model = AutoModelForSequenceClassification.from_pretrained('bert-base-uncased')
model = get_peft_model(model, lora_config)

# Only 0.1% of parameters are trainable!
model.print_trainable_parameters()
# Output: trainable params: 294,912 || all params: 109,483,778 || trainable%: 0.27
        </code></pre>

        <p><strong>Benefits:</strong></p>
        <ul>
            <li>Train 100x faster than full fine-tuning</li>
            <li>Use 90% less memory</li>
            <li>Store multiple adapted models efficiently</li>
            <li>Prevents catastrophic forgetting</li>
        </ul>

        <h5>Adapter Layers</h5>

        <h3>Complete Fine-Tuning Workflow</h3>

from datasets import Dataset
import pandas as pd

# Your custom data
data = {

        <h4>Step 2: Tokenize Data</h4>
        <pre><code>
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained('bert-base-uncased')

    return tokenizer(
        examples['text'],
        padding='max_length',
        truncation=True,
        max_length=128
    )

# Tokenize all datasets

        </code></pre>

        <h4>Step 3: Define Metrics</h4>
        <pre><code>
from datasets import load_metric
import numpy as np

def compute_metrics(eval_pred):
    load_accuracy = load_metric("accuracy")
    load_f1 = load_metric("f1")

    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)

    accuracy = load_accuracy.compute(predictions=predictions, references=labels)["accuracy"]
    f1 = load_f1.compute(predictions=predictions, references=labels, average='weighted')["f1"]

    return {"accuracy": accuracy, "f1": f1}
        </code></pre>

        <h4>1. Learning Rate Selection</h4>
        <pre><code>

        </code></pre>

        <h4>2. Gradual Unfreezing</h4>
        <pre><code>
# Phase 1: Train only classifier
for param in base_model.parameters():
    param.requires_grad = False
train(epochs=2)

# Phase 2: Unfreeze top layers
for param in base_model.layer4.parameters():
    param.requires_grad = True
train(epochs=2)

# Phase 3: Unfreeze all
for param in base_model.parameters():
    param.requires_grad = True
optimizer = Adam(model.parameters(), lr=1e-6)  # Lower LR!
train(epochs=2)
        </code></pre>

        <h3>Common Pitfalls and Solutions</h3>

        <ul>
            <li><strong>Catastrophic Forgetting:</strong>
                <ul>
                    <li>Problem: Model forgets general knowledge</li>
                    <li>Solution: Use lower learning rates, gradual unfreezing, or PEFT methods</li>
                </ul>
            </li>
            <li><strong>Overfitting:</strong>
                <ul>
                    <li>Problem: High train accuracy, low validation accuracy</li>
                    <li>Solution: More data augmentation, dropout, early stopping, reduce model capacity</li>
                </ul>
            </li>
            <li><strong>Underfitting:</strong>
                <ul>
                    <li>Problem: Low accuracy on both train and validation</li>
                    <li>Solution: Train longer, increase learning rate, unfreeze more layers</li>
                </ul>
            </li>
            <li><strong>Slow Convergence:</strong>
                <ul>
                    <li>Problem: Loss decreases too slowly</li>
                    <li>Solution: Increase learning rate, use warmup, check data preprocessing</li>
                </ul>
            </li>
        </ul>
